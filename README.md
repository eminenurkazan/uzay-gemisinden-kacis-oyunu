# Uzay Gemisinden Kaçış Oyunu

## Ekip Üyeleri

- Eminenur Kazan
- Zülal Şahin

## Proje Hakkında

Oyun, kaçırılan oyuncunun tutulduğu uzay gemisinden kaçmaya çalışmasını konu almaktadır. Oyuncu, kendisini gözetim altında tutan kişiyi kandırarak ve gemide karşısına çıkan engelleri aşarak çıkışa ulaşmaya çalışacaktır.

Oyuncunun kurtulabilmesi için oyunun son kapısını koruyan NPC ile serbest metin üzerinden konuşması ve NPC'yi kapıyı açmaya ikna etmesi gerekecektir.

## Kullanılacak Teknolojiler

- Unity
- C#
- NavMesh
- Ollama
